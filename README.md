# Секундомер на Qt

Учебное приложение "Секундомер" на C++ / Qt Widgets.

## Возможности

- Запуск и остановка секундомера одной кнопкой.
- Отображение времени с точностью 0.1 секунды.
- Фиксация кругов с выводом времени предыдущего круга.
- Сброс времени и очистка списка кругов.
- Кнопка "Круг" активна только при работающем секундомере.

## Состав проекта

- main.cpp          - точка входа
- mainwindow.h/.cpp - главное окно
- mainwindow.ui     - разметка формы
- stopwatch.h/.cpp  - логика секундомера (QTimer, QElapsedTimer)

## Сборка

Открыть stopwatch.pro в Qt Creator и нажать Run.
